## Observations

- Shortcut hook: `packages/ui/src/hooks/use-keyboard-shortcut.tsx` (143 lines) ignores keys while typing in inputs, textareas or contenteditable (L70-75), scopes listeners to whether a modal is open (`modal` option, L65-75), and resolves conflicts by `priority` (L105-108).
- Single-key actions near the UI they trigger: `useKeyboardShortcut("m", ...)` invite member (`settings/members/page.tsx` L181), `"c"` create UTM template (`ui/modals/add-edit-utm-template.modal.tsx` L161), `"Escape"` back to the list from a link page (`links/[...link]/page-client.tsx` L124), `"Escape"` clears a bulk selection (`ui/links/links-toolbar.tsx` L186).
- Undo toast: `packages/ui/src/hooks/use-toast-with-undo.tsx` shows a sonner toast with the message and an Undo button, and binds Ctrl/Cmd+Z to the same undo while visible; used by `ui/modals/archive-link-modal.tsx` and `archive-domain-modal.tsx` (L43-71).
- URL as state: `packages/ui/src/hooks/use-router-stuff.ts` exposes `queryParams({ set, del, replace })` over `useSearchParams`, so filters, sort and pagination live in the query string; it also restores the dashboard's nested scroll position after URL updates (`consumePendingDashboardScrollTop`, L11-16).
- OG images: `apps/web/app/api/og/analytics/route.tsx`, `apps/web/app/api/og/avatar/[[...seed]]/route.tsx` generate images per entity.
- 404: `apps/web/app/not-found.tsx` with `not-found-hint.tsx`.
- Account deletion: `apps/web/ui/account/delete-account.tsx`.
- Sign-in: Google, GitHub, SAML SSO and email in one card (screenshot `secret-handling-review/evidence/2026-11-04/reference/app_dub_co_login.png`); unknown app paths go to sign-in (`secret-handling-review/evidence/2026-11-04/reference/app_dub_co_zz-404.png`).
